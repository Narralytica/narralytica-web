# Narralytica Web

Narralytica is a crypto market context and analysis terminal. The website presents ETF flows, leverage, market structure, sectors, macro/news, watchlists, and daily desk context in one dashboard.

It is not a trading signal app, portfolio-only tracker, or buy/sell recommendation engine.

## What The Website Does

- Renders the Narralytica market intelligence dashboard.
- Reads structured terminal payloads generated by the backend.
- Helps users scan market pulse, flow, leverage, sector rotation, catalysts, and desk commentary.
- Presents context and decision-support without making direct trade calls.

## User Value

Narralytica helps active crypto users answer:

- What is moving?
- Why might it be moving?
- Are flows, leverage, sectors, and news confirming the move?
- What should be watched next?

## Data Pipeline

```text
Backend data fetchers
        ↓
website_data/terminal/*.json
        ↓
/api/terminal-data
        ↓
Dashboard cards, desk brief, sectors, news, and analysis views
```

In the current website, `/api/terminal-data` reads the prepared terminal payloads from Supabase storage. The backend is responsible for fetching, calculating, generating, and publishing those payloads.

## APIs Used

| API / Endpoint | Used For | Output In The Website |
| --- | --- | --- |
| `GET /api/terminal-data` | Reads prepared terminal payloads | Main dashboard data for pulse, structure, analysis, events, watch, and desk views |
| `GET /api/hot-news?days={days}&page_size={page_size}` | Website helper route for SoSoValue hot news | Expanded news cards and event impact map headlines |
| `GET https://api.sosovalue.xyz/openapi/v1/news/hot?start_time={ms}&end_time={ms}&page={page}&page_size={page_size}&language=en` | SoSoValue hot news feed | News/event expansion and event-map headline overlay |
| `GET https://mainnet-gw.sodex.dev/futures/fapi/market/v1/public/q/kline?symbol=BTC-USD` | BTC chart candles | Terminal price chart and relationship chart |
| `GET https://mainnet-gw.sodex.dev/futures/fapi/market/v1/public/q/kline?symbol=ETH-USD` | ETH chart candles | Terminal price chart and relationship chart |
| `GET https://mainnet-gw.sodex.dev/futures/fapi/market/v1/public/q/kline?symbol={AAPL-USD,TSLA-USD,NVDA-USD,MSFT-USD,AMZN-USD,XAUT-USD,CL-USD,GOLD-USD,USTECH100-USD,US500-USD}` | Equity, commodity, and macro proxy candles | Relationship module comparison paths |
| `GET https://mainnet-gw.sodex.dev/pro/p/quotation/kline?symbol={vSOL_vUSDC,vSUI_vUSDC,vDOGE_vUSDC,vBNB_vUSDC,vLINK_vUSDC,vXRP_vUSDC,vAVAX_vUSDC}` | Altcoin spot/perp quote candles | Terminal and relationship-module price paths |
| `GET https://mainnet-gw.sodex.dev/pro/p/quotation/kline?symbol={MAG7ssi/USDC,DEFIssi/USDC,MEMEssi/USDC}` | SOD3X/SoSoValue-style index quote candles | Relationship module narrative/index comparisons |
| Backend SoSoValue endpoints | ETF flows, sectors/indices, macro/news, crypto stocks, BTC treasuries | Displayed through `/api/terminal-data` payloads |
| Backend Binance endpoint | Futures long/short positioning | Displayed through `/api/terminal-data` payloads |
| Backend xAI endpoint | Daily desk brief generation | Displayed as the desk brief |

## User Flow

1. Open the dashboard.
2. Scan the terminal overview for market pulse and price context.
3. Review flow, leverage, structure, and sector rotation.
4. Check macro/news catalysts and event impact.
5. Read the desk brief for a daily context summary.
6. Use the watch boards to monitor crypto-linked equities and BTC treasury exposure.

## Main Data Displayed

- Crypto market cap, fear and greed, funding, and open interest.
- BTC/ETH ETF flows and flow intensity.
- Liquidity depth and cost-to-move views.
- SoSoValue sector and index rotation.
- Macro calendar and hot news catalysts.
- Daily desk brief and watchlist context.
- BTC treasury board and equity proxy board.

## Main Routes And Folders

- `app/page.tsx`  
  Main dashboard shell.
- `app/api/terminal-data/route.ts`  
  Server route that returns terminal payloads to the UI.
- `app/api/hot-news/route.ts`  
  Hot-news helper route for the event map and expanded news views.
- `components/narralytica/market-terminal.tsx`  
  Terminal, desk, pulse, structure, events, and watch UI.
- `components/narralytica/relationship-module.tsx`  
  Relationship chart and event impact map.
- `lib/`  
  Formatting and shared helpers.


Build:

```bash
npm run build
```

## Environment Variables

The website needs read access to the terminal payload store:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

The route also accepts:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Provider API keys, xAI keys, and Supabase service-role publishing credentials belong to the backend environment.
